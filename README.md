# The Westshore Grand — Financing Memorandum Microsite

A single-page, self-contained microsite for the **$48.1M acquisition & repositioning financing** of
**The Westshore Grand, A Tribute Portfolio Hotel** (325 keys · Tampa, FL), offered by **Hodges Ward Elliott**.

> **Confidential.** This site presents a confidential financing memorandum prepared for prospective lenders.
> Do not distribute publicly.

## What's here

- `index.html` — the entire site (inlined CSS + JS; no build step)
- `assets/` — images, brand logos, gold line-icons, and the leaf background

## Sections

Introduction · The Property (gallery) · Capital Stack (Sources & Uses, Loan Request) ·
Loan Performance (NOI chart + historical/projected table) · Investment Highlights ·
Location + interactive demand-generator map · Sponsor / Manager / F&B overviews ·
Brand Strength (Marriott / Tribute Portfolio) · Access the Financing Memorandum · Footer.

## Viewing

Open `index.html` in any modern browser — no server required. Fonts, the Leaflet map, and map
tiles load from CDNs, so an internet connection is needed for those to render.
